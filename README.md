# Розумний калькулятор

Легкий вебзастосунок (PWA) для повсякденних підрахунків: точна десяткова арифметика, постійна історія, назви, мітки й примітки до записів.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тести обчислювального ядра
npm run build    # збірка в dist/
npm run preview  # перегляд зібраної версії (з офлайн-режимом)
```

## Як влаштовано

- `src/core/evaluate.ts`: розбір і обчислення виразу на decimal.js (50 значущих цифр). Підтримує `+ − × ÷`, дужки, відсотки (`200 + 10%` = 220), кому й крапку як роздільник, запис `1e-20`.
- `src/core/format.ts`: округлення для показу. Знак `≈` позначає округлене значення, `=` точне. Дуже малі й великі числа показуються як `2 × 10⁻²⁴`.
- `src/core/search.ts`: пошук за виразом, результатом, назвою, приміткою, `#міткою`.
- `src/storage/db.ts`: історія в IndexedDB браузера. Кількість знаків після коми зберігається в localStorage.
- `public/sw.js`: кешування для роботи без інтернету (лише у зібраній версії).
